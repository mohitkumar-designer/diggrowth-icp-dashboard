# DiGGrowth ICP Intelligence & Competitor Analysis Dashboard

A modern, high-performance UI/UX analytics dashboard built for ICP (Ideal Customer Profile) intelligence and competitor market displacement analysis.

## ✨ Features
- **ICP Analysis**:
  - Top Segments (multi-dimensional clusters: Vertical, Category, Headcount, Revenue, Geo)
  - Vertical Insights (interactive market share cards)
  - Customer Analysis (searchable & sortable table of 4,832 accounts)
  - Scored Prospects (ML Lookalike & rule-based scoring models)
  - Prospects by Segment
  - Seasonality Analysis (closed-won timelines with Chart.js)
  - Contact Scores (unified buyer intelligence)
  - Pareto Threshold & Concentration Breakdown
- **Competitor Analysis**:
  - 10 Market Incumbents (Samsara, Motive, Geotab, Verizon Connect, etc.)
  - Customer Book (136 observed accounts)
  - Direct Displacement Overlap (54 accounts)
  - 3,000 Lookalikes with similarity meters
- **Modern Design**:
  - Dual Theme: Light and Dark mode with dynamic SVG logo swapping
  - Universal **Poppins** typography
  - 100% vector SVG icons (zero emojis)
  - Instant CSV exports across all views

## 🚀 Running Locally
```bash
# Using Bun (Hot-reload enabled)
bun run dev

# Or with Node.js
node server.js
```
